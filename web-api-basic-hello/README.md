# Web API Basic Hello

## Descrição
Simples servidor HTTP que responde com "Hello World" na rota raiz.

## Como Executar

```bash
# Instalar dependências (se necessário)
npm install

# Iniciar o servidor
npm start
```

O servidor rodará em: `http://localhost:3000`

## Testes

### Via cURL
```bash
curl http://localhost:3000/
```

Resposta esperada:
```
Hello World
```

### Via Browser
Abra o navegador e acesse: `http://localhost:3000/`
